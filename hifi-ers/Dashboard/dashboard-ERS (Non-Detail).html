Catatan & Info Dashboard ERS

Spesifikasi Hifi ERS (Power Inspect Style):

  • Tampilan dikonversi persis mengikuti standar live Power Inspect PLN.
  • Navigasi Rail Sidebar 80px dengan icon seragam.
  • Top contact header terpasang (helpdesk.pi@iconpln.co.id).
  • Peta Leaflet mendukung 3 tab: Set ERS, Tower Operasi, dan Tower Operasi Terpasang (berbasis nomor Perencanaan PTE... dan Perizinan INS...).
  • Popup card peta menampilkan rincian nomor permit, perencanaan, tower, unit pelaksana, PIC, tanggal pasang, dan rencana bongkar.
  • Tabel data 15 kolom otomatis tersinkronisasi dengan tab terpilih, mendukung pencarian dan sorting.
  • Filter modal menggunakan standard input UI PLN (Segmented Pill untuk single select <= 3 opsi).
