Notes & Validasi Asset Register

  • Fitur: Pemisahan 2 Section: Data Aset (eksisting/operasi) & Pengajuan (tambah data & alur approval).
  • Hirarki Unit Header:
    • User UIT/UPT/ULTG: Menampilkan nama unit langsung (contoh: ULTG Surabaya Utara, UPT Surabaya, UIT JBM).
    • User GI (Multiple): Menampilkan N - Gardu Induk sebagai badge pill yang dapat diklik untuk membuka modal rincian gardu induk.
  • Validasi Field: Techidentno, Merk, Type, Serial ID, Phasa, & Penempatan Lokasi wajib terisi.
  • User Creator (8 Peran Pengaju):
    • Staff GI / TL/SPV GI (Level Gardu Induk)
    • Staff ULTG / TL/SPV ULTG (Level Unit Layanan Transmisi)
    • Staff Asdig UPT / Asman UPT / TL Asdig UPT (Level Unit Pelaksana)
    • Staff Manset UIT (Level Unit Induk Transmisi)
  • Standard UI: Segmented button tanpa icon (text-only), multi-select/single select PLN standard.
