Pengaturan Integrasi API

Konfigurasikan Web App URL dari Google Apps Script dan Token rahasia. Sesuai arsitektur, API_TOKEN dipakai di UI ini, sementara AGENT_TOKEN (terbatas) disimpan khusus di konfigurasi agent.

Info Keamanan Token:
• API_TOKEN memiliki akses penuh membaca dan menulis seluruh task di browser.
• AGENT_TOKEN hanya dapat mengakses task dengan status owner = agent dan tidak memiliki akses foto.
